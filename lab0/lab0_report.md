В данной лабороторной работе мне нужно было создать новый репозиторий devops-lab-pomortseva. Сделала я это через сайт GitHub. После создания репозиторя я клонировала его себе на компьютер (в директорию Desktop) командой git clone https://github.com/pomorcheva/devops-lab-pomortseva.git

После клонирования я создала нужные файлы (.gitignore - включила туда типы файлов, которые не будут задействованы при пуше в мой репозиторий, CONTRIBUTING.MD - описала правила использования реаозитория, README.MD - добавила контактные данные и план изучения курса). Затем я использовала команду git add . чтобы включить все файлы в коммит, затем использовала git commit -m "Initial project setup" чтобы дать название коммиту, затем прописала команду git branch -M develop чтобы создать ветку и переключиться на нее. В заключении работы мне нужно было отправить все изменения в репозиторий кодмандой git push -u origin develop.
